## What this run did

**1. `msf run` is wired ALL-real by default** (`src/cli.ts`):

- The default runtime is now the REAL Sandcastle runtime — `--model
  <provider/model-id>` is demanded at boot, before any keyring read. Works
  for both `--once` and continuous; both flow through the same `wireRunDeps`.
- `wireRunDeps(config, workspace, { model, seams })` is the exported wiring
  function: default path = real GitHub adapter (`createGitHubAdapter`, the
  keyring boot check of ticket 16) + real Sandcastle runtime + real local
  git host. The `seams` object (tracker · runtime · git) is the ONE injection
  point, and only tests pass it — no CLI flag can reach the fake adapter,
  and the binary's default path is unreachable by any fake.
- `--runtime fake` remains accepted (tests only): it selects the placeholder
  that never launches; the boot check still runs. No model needed for it.
- The cli executes `main()` only when invoked as the bin (real-path check,
  symlink-safe) — the module is importable, which is how the e2e drives the
  real wiring offline.
- Flag validation order pinned by tests: config load first (bad config
  fails fast), then runtime flags (bad flags fail without touching the
  keyring — the selection e2e stays offline), then the keyring boot check.
- Wiring gaps closed on the way: the worker's blocked label now comes from
  the CONFIG's label vocabulary (it silently defaulted to
  `agent-blocked` even under a custom vocabulary), and the profile-snapshot
  settings are fed from the config (below).

**2. Profile-snapshot allowedRoots — derivable, fixed in code/config**
(`src/config.ts`, `src/runtime/profile-snapshot.ts`):

- New optional config keys: `profile-allowed-roots` (list of paths,
  tilde-expanded) and `profile-skip-dangling-links` (bool).
- Defaults fixed in code = exactly the roots the ticket-17 live proof
  declared: `~/dev/github.com/Sanmoo/dotfiles`, `~/.agents`,
  `~/.local/share/omarchy` (`DEFAULT_PROFILE_ALLOWED_ROOTS`).
- `profile-snapshot.ts`: a declared allowed root that does not exist on the
  machine is skipped WITH a warning (a missing root cannot be a link target;
  the fail-closed rule is about links, never about absent roots) —
  previously a missing default root would have thrown ENOENT on every launch.
- A real launch therefore reproduces the ticket-17 proof's fail-closed
  snapshot behavior from config alone; a stale-profile-link launch blocker
  is one config line away (`profile-skip-dangling-links: true`).

**3. Boot reconciliation — verified, NOT rebuilt**: the first derivation of
BOTH `runOnce` and `runForever` is `deriveAndAct()`, which scans the
registry (`trabalhos/` — the disk facts that survive a restart) and re-derives
every reserved work from the tracker alone: unreconciled falls (release,
or block on the 2nd consecutive), feedback rounds, retomadas, dones
(archive), rejections, done-fallback. No in-memory state is consulted; no
new code was needed. Proven in the new e2e (below) with a fresh engine
after a "crash" seeded only on disk + tracker.

**4. e2e offline over the REAL cli wiring** (`src/e2e/default-wiring.test.ts`,
6 tests): real `msf.yaml` file → `loadConfigFrom` → `wireRunDeps` with ONLY
the two fake seams injected (tracker adapter + scripted runtime) and the
REAL `localGitWork` pointed at a local bare fixture — zero network, zero
REST, real temp workspace, real git:

- full sweep: claim (label swap BEFORE launch) → launch → collect → ruler →
  `desfecho.json`/`log-1.jsonl`/`sessao/` on real disk, PR open, claim held;
- boot reconciliation ×4: crash footprint → release → relaunch NUMBERED
  attempt 2 from the registry (never a re-run of attempt 1); 2nd consecutive
  fall → blocked + the exact outcome commented; PR parked (restart launches
  nothing, claim held); human feedback across a restart → feedback round on
  the SAME PR, attempt 2, worker closes the round with the comment;
- the default wiring (no seams) demands the keyring credential at boot —
  `MissingCredentialError` naming the account, offline (the token lookup is
  a local keyring read), and nothing was launched or cloned on refusal.

**5. RUNBOOK** (`docs/RUNBOOK.md`, linked from README): the exact live-proof
script — once (config + `msf run --once --model …`), continuous (feedback
rounds on the same branch/PR, Ctrl-C to end), `msf status`; what the human
does (comment on the PR, merge); the REST budget note (60/h shared with the
machine; one sweep = one listing per repo + a handful of per-work calls).
