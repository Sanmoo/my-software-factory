## O que foi implementado

### 1. Régua da fábrica — `src/state/outcome.ts`
- `classifyOutcome(facts): OutcomeRuling` — as **seis classes → transições decididas**, aplicada na coleta (`loop.ts`, no ato do fim do worker):
  1. registro `pr-open` com PR confirmado aberto → `reserve` (claim segurado esperando o humano);
  2. queda sem PR, 1ª consecutiva → `release` (`releaseClaim` agora devolve o label ready — swap claimed→ready; branch fica);
  3. queda sem PR, 2ª consecutiva → `block` (`blockClaim` swap claimed→blocked, claim segue segurado) + comentário na issue com o **desfecho exato** (JSON verbatim do registro, ou declaração estruturada de ausência);
  4. registro **ausente** = queda abrupta (classe nunca escrita em disco) → mesma régua de 2/3;
  5. PR pré-existente → reservado, sem queda registrada — a exceção cobre tanto a derivação (issue com PR não entra na piscina; sem lançamento) quanto a coleta (PR aberto vira `reserve` mesmo com registro de queda);
  6. auto-relato de blocked (classe `blocked-self-report` no registro **ou** label blocked na issue) → `record-only`: a fábrica não transita nada, só registra.
- A classificação lê **só fatos estruturados**: campo `class` do registro, PR via porta, labels via porta, consecutividade via registro em disco. Zero prosa; registro inválido/corrompido = ausente = queda abrupta.

### 2. Registro por trabalho — `src/pool/registry.ts`
- `readLaunchFacts(workDir)`: nº da tentativa (campo `attempt` do desfecho anterior, fallback ao maior `log-<n>.jsonl`) + `previousFall` (registro anterior é queda limpa; ou evidência de tentativa sem registro = queda abrupta anterior). Dir inexistente → tentativa 1, sem queda prévia.
- `scanRegistry(workspace)`: a visão do `msf status` — `trabalhos/<repo>#<n>/` **sem** desfecho = em voo (órfão com a fábrica parada); **com** = último desfecho; `arquivo/` = dones. Workspace inexistente lê vazio.

### 3. Artefatos escritos pelo runtime — `src/runtime/fake-runtime.ts`
- A cada lançamento a sessão escreve `sessao/` + `log-<n>.jsonl` (linha `session-start`); desfecho roteirizado escreve `desfecho.json` + linha `session-end`. Morte abrupta deixa exatamente o início sem fim — a pegada que o registro lê de volta.

### 4. Porta — `src/tracker/port.ts` (+ fake adapter)
- `releaseClaim(ref, account, readyLabel?)` — forma antiga preservada; com label ready devolve o trabalho à piscina.
- `blockClaim(ref, claimedLabel, blockedLabel)` — novo op, o swap claimed→blocked da régua (claim segue segurado até o estado terminal).

### 5. `msf status` — `src/state/status.ts` + `cli.ts`
